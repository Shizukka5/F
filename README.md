# ChunkSwap

Fabric mod for Minecraft 1.21.1: break a block and the area around it turns into that block.

- 7 modes: chunk, layer, sphere, cube, above, below, checkerboard
- Random block mode, chance setting
- Settings screen via Mod Menu + Cloth Config, plus `/chunkswap` command
- Config: `config/chunkswap.json`

Build: `gradle build` (Java 21). The jar appears in `build/libs/`.
