# ChunkSwap

**Break a block — and the whole chunk turns into it.**

Mine a single block of dirt and the entire chunk becomes dirt. Mine diamond ore and the chunk is a solid diamond block mass. Chaotic, silly and great for challenges, streams and survival with friends.

## Features

- **7 swap modes:** whole chunk, chunk layer, sphere, cube, chunk above the block, chunk below the block, checkerboard chunk.
- **Random block mode:** the area turns into a random block instead of the one you broke.
- **Chance:** set the probability (1–100%) that a broken block triggers the effect.
- **Smooth, lag-friendly:** the swap is spread across several ticks, so the game doesn't freeze. You choose the speed.
- **In-game settings menu** (with Mod Menu + Cloth Config) and the `/chunkswap` command.
- Bedrock is never replaced. Air stays air. Chest contents are removed without dropping items.

## Commands (operators only)

| Command | What it does |
| --- | --- |
| `/chunkswap` | Shows the current status and settings |
| `/chunkswap on` / `off` | Turns the effect on or off |
| `/chunkswap reload` | Reloads `config/chunkswap.json` |

## Settings

Open **Mod Menu → ChunkSwap → configure**, or edit `config/chunkswap.json`. This needs **Mod Menu** and **Cloth Config** (both optional).

## Requirements

- Minecraft **1.21.1**, Fabric Loader, **Fabric API**
- Optional: Mod Menu and Cloth Config (for the settings screen)
- Works in singleplayer and on servers (install on the server; clients don't need it).

## Warning

The mod destroys terrain. **Make a backup of your world** before playing.

# ChunkSwap (по-русски)

**Сломал блок — и весь чанк превратился в него.**

Выкопали один блок земли, и весь чанк стал землёй. Сломали алмазную руду, и весь чанк превратился в алмазную руду. Хаотично, смешно, отлично подходит для челленджей, стримов и выживания с друзьями.

## Возможности

- **7 режимов замены:** весь чанк, слой чанка, сфера, куб, чанк выше блока, чанк ниже блока, чанк в шахматном порядке.
- **Случайный блок:** область превращается в случайный блок вместо сломанного.
- **Шанс срабатывания** от 1 до 100%.
- **Без жёстких лагов:** замена растягивается на несколько тиков, скорость настраивается.
- **Меню настроек в игре** (через Mod Menu и Cloth Config) и команда `/chunkswap`.
- Бедрок не заменяется, воздух остаётся воздухом, содержимое сундуков пропадает без выпадения предметов.

## Команды (только для операторов)

| Команда | Что делает |
| --- | --- |
| `/chunkswap` | Показывает статус и настройки |
| `/chunkswap on` / `off` | Включает или выключает эффект |
| `/chunkswap reload` | Перечитывает `config/chunkswap.json` |

## Настройки

**Mod Menu → ChunkSwap → настроить** либо файл `config/chunkswap.json`. Для меню нужны **Mod Menu** и **Cloth Config** (необязательные).

## Требования

- Minecraft **1.21.1**, Fabric Loader, **Fabric API**
- Необязательно: Mod Menu и Cloth Config
- Работает в одиночной игре и на серверах (ставится на сервер, клиентам не нужен).

## Предупреждение

Мод разрушает ландшафт. **Сделайте резервную копию мира.**
